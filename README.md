# 🌐Обзор
**Korder** - это система управления заказами.

## ⚡ Функции
* Управление заказами.
* Управление товарами.
* Управление пользователями.
* REST API.
* Предустановленные роли (USER, ADMIN).
* JWT-аутентификация.
* Хранение секретов в `.env`.

# 📥 Установка
#### 1️⃣ Клонируйте репозиторий:
```bash
git clone https://github.com/GnomeShift/Korder && cd Korder
```

#### 2️⃣ Сконфигурируйте `.env`
```bash
nano .env
```

#### 3️⃣ Запустите сборку проекта
```bash
./gradlew run 
```
